MOTORIKA Production Automation

Internal production automation service for MOTORIKA Operations.

About

MOTORIKA Production Automation is an internal administrative tool used to automate deployment and maintenance of Google Apps Script projects belonging to MOTORIKA Operations.

The application connects GitHub Actions to Google Apps Script APIs so authorized administrators can manage Apps Script project content, deployments and application storage without performing each production operation manually.

Google account access is used only for these administrative automation functions and only by authorized MOTORIKA administrators.
