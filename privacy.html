Privacy Policy

MOTORIKA Production Automation

Last updated: August 23, 2026

1. Purpose of the application

MOTORIKA Production Automation is an internal administrative application used by authorized MOTORIKA administrators to automate management and deployment of Google Apps Script projects through GitHub Actions.

2. Google user data accessed

The application requests only the Google OAuth permissions required for its administrative automation functions.

These permissions allow the application to access and manage:

  • Google Apps Script project content and project information;
  • Google Apps Script deployments;
  • data associated with the authorized Apps Script application.

The application does not request access to Gmail, Google Drive, Google Contacts, Google Calendar, or other unrelated Google services.

3. How Google user data is used

Google user data is used only to perform authorized administrative automation for MOTORIKA Operations, including managing Apps Script projects and deployments.

Google user data is not used for advertising, marketing, profiling, or any unrelated purpose.

4. Storage and security

OAuth credentials required by the automation are stored as encrypted GitHub Environment secrets and are not stored in the public website or public repository content.

Access tokens are used only to authenticate requests to Google APIs. Refresh credentials are retained only for as long as necessary to operate the authorized automation and may be revoked or replaced by an authorized administrator.

5. Sharing of data

Google user data is not sold, rented, or shared with advertisers.

Data and authentication credentials may be processed by the technical infrastructure required to operate the service, including Google APIs and GitHub Actions, solely for the purpose of executing the authorized automation.

6. Data retention and deletion

MOTORIKA Production Automation does not maintain a separate database containing Google user data obtained through Google APIs.

An authorized administrator may revoke the application's Google Account access at any time and may remove or replace stored OAuth credentials.

7. Limited use

MOTORIKA Production Automation's use of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements.

8. Changes to this policy

This Privacy Policy may be updated if the application's functionality or handling of Google user data changes. The current version will remain available on this page.

9. Contact

Privacy questions regarding MOTORIKA Production Automation may be directed to the administrator using the support contact associated with the application's Google OAuth configuration.
